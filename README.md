# ColourDrop

ColourDrop is a native macOS menu bar color dropper for quickly sampling a screen color and copying its HEX value.

## Requirements

- macOS 13.0+
- Xcode 15 or newer

## Usage

1. Launch ColourDrop.
2. Click the menu bar icon.
3. Choose **Pick Color**.
4. Click a color anywhere on screen.
5. The HEX value is copied automatically.

The menu keeps the last sampled HEX and RGB values available for quick copying.
